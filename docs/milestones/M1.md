## Exercise

`read_first_line` opens the path supplied on the command line and prints its first line. The local `std::ifstream` manages the file resource. Its destructor closes an open file when execution leaves the scope, including on an early return after a read failure. This is resource acquisition is initialization (RAII). A local `std::string` owns the text read from the file.
