## Learning checkpoint

A leader receives `PUT color blue` while both followers are unreachable. Can it acknowledge success? What must happen before the command can be committed and applied?

The developer identified the majority requirement. While the leader is isolated, it cannot acknowledge the write as committed. If it remains leader in the same term, it can commit the current-term entry once the entry is replicated on the leader and one follower. It applies the committed command before acknowledging success.
